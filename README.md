# Калька

https://buzulutskiy.github.io/kalka/

Камера телефона смотрит на рисунок, поверх ложится референс. Стоп-кадр —
и картинку можно спокойно двигать, пока не сядет по пропорции.

## Что умеет

- **Референс поверх камеры.** Пальцем двигать, двумя — размер.
  Поворота нет намеренно: он только сбивает. Прозрачность — главный
  ползунок внизу. В комплекте исходный референс (`ref-default.png`),
  выбирать картинку вручную нужно, только если нужна другая.
- **Зафиксировать.** Замораживает кадр с камеры — руки дальше не дрожат,
  телефон можно положить. Референс при этом остаётся живым: его двигают
  и масштабируют прямо по застывшей фотографии. Обратно — «живая камера».
- **Лупа.** Переключает жесты на сцену: пальцы приближают кадр вместе с
  референсом, сама картинка при этом стоит. Двойное касание — 1:1.
- **Три режима.** «Фото» — картинка как есть; «контур» — из неё вынимаются
  только линии (Собель с порогом по перцентилю), поверх карандаша это
  читается лучше всего; «разница» — mix-blend-mode: difference, совпавшее
  уходит в чёрный, разошедшееся светится.
- **Мигание.** Референс включается-выключается раз в 0,6 с — глаз ловит
  сдвиг пропорции там, где на статике его не видно.
- **Зеркало и сетка.** Зеркало переворачивает всю сцену — старый приём
  «посмотреть на рисунок свежим взглядом». Сетка — трети и диагонали.
- **Снимок.** Сохраняет то, что видно на экране (через «Поделиться» на
  телефоне, файлом — на десктопе).

Референс и настройки лежат на устройстве (IndexedDB + localStorage),
никуда не уходят. Работает офлайн после первого открытия.

## Без камеры

Кнопка «без камеры — открыть снимок» на старте: вместо живой картинки
берётся фотография рисунка. Тот же разбор, только с телефона в руке
ничего держать не надо.

## Оговорка

`getUserMedia` работает только по https (или на localhost). На GitHub
Pages всё в порядке; при открытии файла с диска камера не включится.
